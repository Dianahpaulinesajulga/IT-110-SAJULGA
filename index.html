15 HTML Tags I Learned

  • html - used to create an HTML document
  • head - contains information about the webpage
  • title - gives a title to the webpage
  • body - contains the content of the webpage
  • h1 - used for the main heading
  • h2 - used for a smaller heading
  • p - used to create paragraphs
  • strong - makes important text bold
  • ul - creates an unordered list
  • li - creates an item in a list
  • br - adds a line break
  • hr - creates a horizontal line
  • a - creates a link
  • img - displays an image
  • div - groups content together

HTML is used to create the basic structure of a webpage. HTML tags help organize the text and content of a website.
